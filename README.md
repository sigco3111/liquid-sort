# Liquid Sort

플레이어는 색깔이 있는 액체를 올바른 시험관에 정렬해서 높은 점수를 얻는 게임입니다.

실행주소1 : https://sigco3111.github.io/liquid-sort/

실행주소2 : https://dev-canvas-pi.vercel.app/

## ✨ 주요 기능

- **동적 레벨 생성**: 레벨이 올라갈수록 점진적으로 난이도가 높아지는 무한한 레벨을 즐길 수 있습니다.
- **물리 기반 붓기 애니메이션**: SVG 필터(`gooey` 효과)를 사용하여 액체가 한 튜브에서 다른 튜브로 부드럽게 흘러 들어가는 시각적으로 만족스러운 애니메이션을 구현했습니다.
- **점수 및 통계 시스템**: 각 레벨을 완료하면 **이동 횟수**와 **소요 시간**을 기반으로 점수가 계산됩니다.
- **영구적인 게임 상태**: `localStorage`를 사용하여 현재 레벨 진행 상황과 전체 게임 기록(클리어한 레벨, 총점 등)을 저장하므로, 언제든지 게임을 중단했다가 다시 시작할 수 있습니다.
- **상세한 대시보드**: 레벨을 완료하면 해당 라운드의 통계와 전체 누적 기록을 보여주는 세련된 대시보드가 나타납니다.
- **실시간 점수 표시**: 게임 화면 상단에서 누적 총점을 실시간으로 확인할 수 있어 동기 부여가 됩니다.
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 등 다양한 화면 크기에서 완벽하게 작동합니다.
- **완벽 한글화**: 모든 UI 텍스트가 한국어로 제공됩니다.

## 🎮 플레이 방법

1.  **목표**: 모든 액체를 색깔별로 분류하여 각 시험관에 하나의 색깔만 가득 채우세요.
2.  **조작**:
    - 액체를 옮기려면 먼저 소스가 될 튜브를 클릭하여 선택합니다.
    - 그 다음, 액체를 부을 목적지 튜브를 클릭합니다.
3.  **규칙**:
    - 액체는 같은 색상의 액체 위나 비어있는 튜브로만 부을 수 있습니다.
    - 목적지 튜브에 액체를 받을 충분한 공간이 있어야 합니다.

## 💯 점수 시스템

더 높은 점수를 얻기 위해 전략적으로 플레이하세요! 점수는 다음과 같이 계산됩니다.

- **기본 점수**: 각 레벨은 10,000점의 기본 점수로 시작합니다.
- **감점 요인**:
  - **이동 횟수**: 액체를 옮길 때마다 100점씩 감점됩니다.
  - **소요 시간**: 레벨을 완료하는 데 걸린 시간(초)마다 10점씩 감점됩니다.

> **팁**: 가장 적은 횟수로, 가장 빠르게 레벨을 완료하여 최고 점수에 도전하세요!

## 🛠️ 기술 스택

- **프레임워크**: [React](https://react.dev/)
- **언어**: [TypeScript](https://www.typescriptlang.org/)
- **스타일링**: [Tailwind CSS](https://tailwindcss.com/)
- **아이콘**: [Lucide React](https://lucide.dev/)
- **모듈 로딩**: CDN([esm.sh](https://esm.sh/))을 통한 네이티브 ES 모듈 (별도의 번들링 과정 없음)

## 🚀 시작하기

이 프로젝트는 별도의 빌드 과정 없이 바로 실행할 수 있습니다.

1.  **저장소 복제(Clone)**:
    ```bash
    git clone https://github.com/your-username/liquid-sort-game.git
    cd liquid-sort-game
    ```

2.  **로컬 서버로 실행**:
    간단한 HTTP 서버를 사용하여 프로젝트를 실행합니다. `npx`를 이용하면 별도 설치 없이 바로 실행할 수 있습니다.

    ```bash
    npx serve
    ```

3.  **브라우저에서 열기**:
    터미널에 표시된 URL(보통 `http://localhost:3000`)을 웹 브라우저에서 엽니다.
